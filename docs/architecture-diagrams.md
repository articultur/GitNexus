## 📦 仓库布局

```
GitNexus (monorepo)
├── gitnexus/                    # CLI/MCP 核心包 (npm: gitnexus)
│   ├── src/
│   │   ├── cli/                 # 命令行工具 (analyze, query, serve, mcp)
│   │   ├── core/
│   │   │   ├── ingestion/       # 索引管道 (43个处理器，支持多语言解析)
│   │   │   ├── graph/           # 知识图谱构建
│   │   │   ├── lbug/            # LadybugDB 图数据库适配器
│   │   │   ├── search/          # BM25 混合搜索
│   │   │   ├── embeddings/       # 向量嵌入生成
│   │   │   ├── wiki/             # Wiki 生成
│   │   │   └── tree-sitter/      # Tree-sitter WASM 封装
│   │   ├── mcp/                  # MCP 协议服务 (stdio + HTTP bridge)
│   │   ├── server/               # Express API 服务
│   │   └── storage/              # 仓库注册表管理
├── gitnexus-web/                # React/Vite Web UI (WASM 索引)
├── eval/                        # Python 评估工具 (SWE-bench)
└── .claude/, plugins/           # AI Agent 技能配置
```

## 📊 核心数据流

| 阶段 | 输入 | 处理 | 输出 |
|------|------|------|------|
| **解析** | 源代码文件 | Tree-sitter WASM | AST + 符号列表 |
| **关系** | AST 符号 | 导入/调用/继承解析 | 图边 (edges) |
| **社区** | 完整图 | Louvain 社区检测 | 社区分组 |
| **流程** | 图结构 | 执行流识别 | 209 个执行流程 |
| **搜索** | 自然语言 | BM25 + 向量混合 | 排名结果 |
| **影响** | 符号名 | 拓扑排序 + 深度分析 | 影响范围报告 |

## 🔧 关键模块

| 模块 | 路径 | 职责 |
|------|------|------|
| **CLI** | `gitnexus/src/cli/` | analyze, query, serve, mcp 命令 |
| **Ingestion** | `gitnexus/src/core/ingestion/` | 43 个语言处理器，导入解析 |
| **Graph** | `gitnexus/src/core/graph/` | 节点/边构建，符号建模 |
| **LadybugDB** | `gitnexus/src/core/lbug/` | 图数据库适配器 |
| **Search** | `gitnexus/src/core/search/` | BM25 混合搜索排名 |
| **MCP** | `gitnexus/src/mcp/` | 协议实现，工具暴露 |
